### About Me

CS student at Pensacola State College, in Florida. I'm self-taught, and the origin story is underwhelming: I was playing Minecraft one day, started programming, and I genuinely don't remember how or why. No inspiring moment, no mentor, just a random event in my past.

I mostly learn by picking a project slightly too big for me and question my life choices along the way. I originally put this README together so my profile wouldn't look empty.

- **Main Stack:** C#, C++, Java, and TypeScript.
- **Focus:** Low-level Windows utilities, shared libraries, and dev tools.
- **Goal:** Expanding my general CS knowledge and picking up Python along the way (still getting used to no curly braces {} :P).
- **Outside of code:** I'm a musician, and I'm getting ready to start contributing to the [MuseScore](https://github.com/musescore/MuseScore) source code.
- **Ask me about:** header-only C++ libraries (actually don't.), memory tooling (again don't.), or Discord bots.

### How I Build Things

- I like **header-only** libraries. Drop in one file, no build system drama.
- I prefer **type-safe, zero-allocation** designs where I can get them. If I'm going to leak something, it's going to be my sleep schedule, not memory.
- I hate **CMake**, but it's the only good option, so I'm stuck fighting an uphill battle.
- I build tools I wish already existed, then realize that a version of the tool already exists and I'm 4 years too late.
- Whenever I stop being lazy, something gets released.
- I like reading other people's source code to figure out how things work, mostly out of nosy curiosity :D
